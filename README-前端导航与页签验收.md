# 前端导航与页签修复验收说明

> 日期：2026-08-25
> 范围：Agent-loop Web 工作台导航、页签和安全的页面内入口

## 改了什么

- 自动化执行的“任务队列、运行中、已完成、已中断”改为真实链接，并保留项目和平台参数。
- 测试报告的“报告概览、批次报告、单条记录、失败分析”改为真实链接，并保留日期、模块、结果、成熟度和基础设施筛选。
- 环境中心“大模型/ONES”的“打开系统设置”会直接进入对应设置页签。
- 更新前端资源版本，避免 Chrome 继续使用旧脚本。
- 增加上述跳转合同的自动化回归测试。

## 影响与提升

- 影响页面：自动化执行、测试报告、环境中心。
- 不影响后端接口、用例数据、执行历史、W30/579 设备链路和安全门禁。
- 页签不再依赖单次 JavaScript 点击事件，浏览器直接访问、刷新和后退更稳定。
- 报告切换页签时不再丢失当前筛选条件。
- 环境配置入口不再打开错误的设置分类。

## 验收结果

- 一级导航 7/7、自动化执行页签 4/4、环境中心页签 4/4、报告页签 4/4 均通过实际浏览器点击验证。
- 用例分类 7/7、ONES 状态筛选 5/5、系统设置页签 3/3 通过。
- 总览页 7 个内部入口、项目切换、W30/579 平台切换、搜索、分页、详情和安全的导入导出入口通过。
- 7 个主路由均返回 HTTP 200，浏览器控制台错误为 0。
- 自动化回归：`815 passed, 17 skipped, 9812 subtests passed`。
- `git diff --check` 通过。

## 已知边界

- “批次报告”和“单条记录”跳转正常，但业务内容仍是暂不支持的占位页。
- 删除记录、创建真实批次、启动测试和蓝牙实机命令会改变数据或设备状态，本轮未执行这些破坏性操作。
